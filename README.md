# lecture-pdf-teacher

把老师的 PDF 课件转化为可以真正用来学习和复习的中文讲义。

`lecture-pdf-teacher` 是一个面向大学生学习场景的 Agent Skill。它能够读取课程 PDF，按照课件原有顺序梳理知识，解释重点概念和公式，并生成适合平时学习与期末复习的 Markdown 笔记。

## 适用场景

- 课前预习：快速了解章节结构、学习目标和先修知识。
- 课后复习：把零散的课堂幻灯片整理成连贯的课程笔记。
- 期中与期末复习：提取重点概念、关键公式、典型例题和常见错误。
- 难点补习：用教师视角解释公式、推导过程、图表和抽象概念。
- 考前梳理：生成重点清单和复习提纲，帮助安排复习顺序。

## 核心功能

- 读取并分析 PDF 课件，尽量保留章节、页面和知识点顺序。
- 用中文解释重要概念、定义、公式、推导、例题和练习。
- 为变量、单位和数学表达式使用 Markdown 兼容的 LaTeX 格式。
- 用文字描述课件中的图表、流程图和示意图，并标记无法确定的内容。
- 总结重点公式、易错点、学习建议和考前复习提纲。
- 将完整讲义保存为与原 PDF 同目录的 Markdown 文件。
- 使用辅助脚本处理输出文件重名，避免覆盖已有讲义。

## 使用方式

在支持 Agent Skills 的环境中，将本仓库作为 `lecture-pdf-teacher` skill 使用，并上传或提供 PDF 课件。可以使用类似下面的请求：

```text
请使用 lecture-pdf-teacher 详细讲解这份 PDF 课件，生成适合期末复习的中文学习笔记。
```

也可以指定学习目标，例如：

```text
请使用 lecture-pdf-teacher 讲解这份信号与系统课件。
重点说明傅里叶变换的推导、公式中每个符号的含义、典型题目的解题方法和期末复习重点。
```

## 兼容性说明

skill 的核心流程位于 `SKILL.md`，采用通用的 Agent Skills 目录结构。不同代理的安装位置、自动发现机制和调用语法可能不同：

- Codex：使用仓库中的 `agents/openai.yaml` 作为界面元数据，并可通过 `$lecture-pdf-teacher` 调用。
- 支持 Agent Skills 规范的其他代理：安装整个 skill 文件夹，并按照其 skill 目录规则加载 `SKILL.md`。
- 不支持自动加载 skill 的代理：在请求中提供本仓库路径，要求代理先读取 `SKILL.md`，再处理 PDF。

本 skill 不依赖固定的 PDF 工具名称。代理应使用自身可用的 PDF 文本提取或 OCR 能力；保存讲义时需要可运行 Python 3 的环境。

## 输出内容

生成的 Markdown 讲义通常包含：

1. 课程内容概览和学习目标
2. 按章节或页面组织的详细讲解
3. 关键公式、符号说明和使用条件
4. 例题、练习题及解题思路
5. 常见误区和复习建议
6. 适合考前快速回顾的复习提纲

默认情况下，笔记会保存为：

```text
<原 PDF 文件名>_讲解笔记.md
```

如果同名文件已经存在，保存脚本会自动生成带序号的新文件，避免覆盖原有笔记。

## 项目结构

```text
lecture-pdf-teacher/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── scripts/
    └── save_lecture_notes.py
```

- `SKILL.md`：skill 的核心工作流程、教学要求和输出规范。
- `agents/openai.yaml`：供 Codex 使用的名称、简介和默认提示词元数据；其他代理可以忽略此文件。
- `scripts/save_lecture_notes.py`：将生成的 Markdown 内容保存到 PDF 所在目录，并处理重名文件。

## 注意事项

- 讲义质量取决于 PDF 的清晰度、文字可提取程度和图表复杂度。
- 扫描版或图片较多的课件可能需要 OCR，公式和图表也可能需要人工核对。
- 生成的内容用于学习辅助，不能替代老师的课堂讲解、教材或考试要求。
- 课程 PDF 和生成的个人讲义通常不应提交到公开仓库；仓库中的 `.gitignore` 已包含相关忽略规则。
- 本仓库只包含 skill 本身，不包含任何特定课程的课件或学习资料。
